#1 Personal ✒️

Personal Note

I’m sorry. I don’t speak binary. I’m counting on you.
- the Mandalorian

This week I finished the 3rd season of the Mandalorien tv series.
It is a great action-adventure space western series.
In one of the scenes the mandalorian is talking to his assistant droid and it replies in binary beeping tones.
As I was watching this scene I thought it is another evidence that science fiction is becoming reality.

Today we talk to the AI assistants and hope for the best. The results we get back are what we asked for. But of course you need to know how to talk to AI. If you just ask plain questions you will very fast get disappointed - but that's because you do not speak binary…
Learning to talk to an AI is like learning a new language. It is not more than that. And I think it is quite remarkable how much it is showing us the mirror - we have unlearned to give clear instructions We throw some words into the room and expect our opposite knows exactly what to do. We got lazy in writing down clear instructions. That will change - now we have our digital assistant whom we need to tell what we want - the good thing is this assistant can also take bullet points and rephrase those in proper text or prompts for us - but you need to learn to at least give some clear instructions about what you expect as the outcome. I love to play around with the different AI tools and chatbots. There is so much new stuff coming every day that you cannot hold on with the speed. But don’t get intimidated by that.
You can ask for help - either a colleague, a friend or your favorite AI - because it speaks binary.

#2 Tech 💻

GitHub Copilot - Agent Mode

This week I was back at coding a bit more - working on that DMS (document management system) App project I mentioned in earlier blogs. This week was a bigger milestone because I got to test the App against real data in the test system - but with a setup that will be the same in the production environment in some weeks.
Tests were successful to far. We could see that the files are transmitted to the DMS and are stored in the right place (based on configuration).
However we also saw some missing functionality (some I was aware of some not) and it would be helpful here and there to have some more information about the file jobs and the relation to the files. All in all a bit more usability for the end-user is still lacking.
So I started typing some code how I would normally do it (manuall by hand) and got the first features done. Once in a while I used centralq.ai to get some help about specific properties.
Then I thought - why do I look up all these details and code myself - may be I can use GitHub Copilot to assist me. I am currently evaluating the use for my company.
I started using the chat in visual studio code but the first results were not so promising. Then I remembered someone recommending to switch the mode to: agent.
This changed quite a lot and the results are really exiting. The agent instantly understood directly what I wanted to achieve and within minutes and 2 instructions later I had implemented a new feature for which I would normally need more than half an hour to code. And I’m not even using the latest model - this is really promising for the near future. I will definitely play around a bit more - that will be fun. Next week I’m attending a tech conference - let’s see if I learn a lot more practical things about how to use the GitHub Copilot. I’m really looking forward to it.

Training Plan - Progress and Goals

Last week, my training progressed quite well, and I felt good about sticking to my plan. I focused on fewer runs, integrated more strength exercises, and continued with various workouts, including attending HYROX classes. I'm pleased to report that I'm seeing and feeling the progress. These dishes are healthy, typically featuring few ingredients and plenty of vegetables. This approach is very convenient and easy to integrate into daily life. We will probably try one or two other options to see if they work in our daily routine, but so far, this is proving to be a very effective and cost-conscious solution.

#4 Inside AI 🤖

Asking for help

I learned a lot this week. Currently I am working with a citizens' initiative on a statement for some new law regulations. You can imagine this is a lot of reading and understanding the drafts. Luckily it is not binary language but still hard to understand. Of course I use AI a lot in the process either to help me research or warp up text, but also to help understand the law language.
I learned that my prompts are not always the best to get the right result. So what do you do then when the AI is not answering how you would expect it? Do we speak different languages? Do I need to learn binary? If so here is a prompt that helps:

Gemini help me learn speaking binary
Result:

Of course there is an easier way - just ask the AI to help you building a prompt that it understands.
Let me give you an example: a colleague asked me to help him with a data problem. He had a list with some data and wanted to enrich the list with additional data in additional columns. He gave me the list and a really simple prompt with instructions. Looked okay to me and I would know what to do. But that research task would takes hours to do. So I just used the prompt and the list with some AI chats to see how they reacted - to keep it short here - not what we wanted…
So I asked the AI to help me with the prompt. It understood what I wanted and it improved the prompt by removing redundant information and made the instructions more clear. Even for me the structure of the prompt is now much clearer and straight forward - and I can save me this prompt and structure for similar future use cases.
Tip: If you are unsure how to approach the problem or how to build the prompt - just ask your favorite AI.
Here is a quick example - I used claude.ai here - it already knows quite a lot about me because I have added a profile with some data about me - basically I added a wrap up of all my recent blogs.

**Here is the full document with recommended approaches and examples:**

I need help crafting an optimal prompt for [specific task/goal].

Context about me:

  • I'm a Microsoft Business Central developer with [X years] experience
  • I blog weekly about personal development, technology, and productivity
  • I'm currently [specific current projects/learning goals]

My goal: [Specific outcome you want to achieve]

Please help me create a focused prompt that will get the best results for this specific task, including:

  1. The right level of technical detail
  2. Appropriate context about my background (only what's relevant)
  3. Clear success criteria
  4. Any specific constraints or preferences

Then execute that refined prompt.

I'm working on [specific BC/AI project]. I need a prompt that will help me:

  • Understand the technical architecture
  • Identify potential challenges with BC APIs/integrations
  • Get actionable code examples
  • Consider best practices for [specific area]

My current technical context: [brief, relevant details]
What I've already tried: [if applicable]

I'm writing a blog post about [topic] for my weekly blog that covers personal development, technology, and productivity.

Help me create a prompt that will:

  • Generate engaging angles that resonate with readers interested in [specific themes]
  • Provide structure that balances technical depth with accessibility
  • Include practical takeaways
  • Reflect my voice: [brief description of your style]

Target audience: [specific reader type]

I'm learning [skill/topic] as part of my continuous learning journey.

Create a prompt that will help me:

  • Get a structured learning path appropriate for my [current level]
  • Connect new concepts to my existing knowledge in [relevant areas]
  • Identify practical application opportunities
  • Set realistic milestones

My learning preference: [how you learn best]
Time commitment: [realistic timeframe]

Before we dive in, ask me 2-3 specific questions that will help you tailor your response to my situation and needs for this particular [task/problem/goal].

I'm going to give you a challenge/question. First, tell me what assumptions you're making about my background, goals, and constraints. Then I'll correct or confirm these assumptions before you provide your main response.

I have a complex [problem type]. Please:

  1. Break down the problem into components
  2. Identify what additional information you need from me
  3. Propose a step-by-step approach
  4. Highlight potential decision points where my input will be crucial
  5. Suggest how we can iterate and refine the solution

I need multiple perspectives on [situation/decision]. Please respond as:

  1. A Microsoft Business Central expert focusing on technical feasibility
  2. A productivity coach considering workflow optimization
  3. A blogger thinking about content potential
  4. A pragmatist focusing on implementation reality

For each perspective, provide the top 2-3 most important considerations.

Here's my initial prompt: [your prompt]

Please:

  1. Identify what might be unclear or missing
  2. Suggest improvements for clarity and specificity
  3. Provide the refined version
  4. Execute the refined prompt

After providing your main response, please also:

  • Rate the relevance to my stated goals (1-10)
  • Identify any assumptions you made
  • Suggest one follow-up question that would improve the next iteration

It was written by Taylor Momsen, Ben Phillips, and Kato Khandwala, and produced by Kato Khandwala.
